# Mohamed Sabry - Front End Developer Portfolio

A modern, interactive 3D portfolio website showcasing professional web development projects and skills. Built with React, Vite, Three.js, and GSAP to create an immersive user experience.

## Features

- **Interactive 3D Experience**: Leveraging Three.js and React Three Fiber for engaging 3D graphics
- **Smooth Animations**: GSAP animations for seamless transitions and interactions
- **Responsive Design**: Fully responsive layout that works across all devices
- **Modern Tech Stack**: Built with React, Vite, and cutting-edge frontend technologies
- **Project Showcase**: Comprehensive display of 12 professional projects with live demos
- **Contact Form**: Integrated contact functionality with EmailJS
- **SEO Optimized**: Enhanced meta tags and structured data for better search visibility

## Technologies Used

- **Frontend Framework**: React.js
- **Build Tool**: Vite
- **3D Graphics**: Three.js, React Three Fiber, React Three Drei
- **Animations**: GSAP, React GSAP
- **Styling**: Custom CSS with modern design principles
- **Contact**: EmailJS integration
- **Development Tools**: ESLint for code quality

## Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd 3d-portfolio-main
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
