## Installation & Setup Guide

### Prerequisites

Ensure Node.js (version 18 or higher) and npm are installed on your local environment.

### Steps to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/mohamed-sabry/awwwards-portfolio.git
   cd awwwards-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
