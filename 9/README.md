# 3D Portfolio

This is a modern 3D portfolio website showcasing front-end development projects and technical expertise. The portfolio features an immersive 3D experience built with Three.js and GSAP animations.

## Live Demo

[View the live portfolio](https://mdamiruddin-3dportfolio.vercel.app)

## Features

- Interactive 3D environment using Three.js
- Smooth scroll animations with GSAP
- Responsive design for all devices
- Dark/Light theme toggle
- Project showcase with live demos
- Professional contact section

## Technologies Used

- Three.js for 3D graphics
- GSAP for animations
- Vanilla JavaScript
- CSS3 for styling
- HTML5

## Setup Instructions

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
