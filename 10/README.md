# Mohamed Sabry - Front End Developer Portfolio

This repository contains the professional portfolio website of Mohamed Sabry, a Front End Developer specializing in modern web technologies. The portfolio showcases various projects and demonstrates expertise in creating engaging digital experiences.

## Demo

View the live portfolio: [Mohamed Sabry Portfolio](https://next-js-creative-portfolio-website.vercel.app/)

## Project Overview

This portfolio website is built using cutting-edge web technologies to provide an immersive and professional experience. It features:

- Modern and responsive design
- Interactive 3D elements using Three.js
- Smooth animations with Framer Motion
- Clean and accessible user interface
- Project showcase with detailed descriptions

## Technologies Used

- **Framework**: Next.js 16.2
- **Styling**: Tailwind CSS 4
- **3D Graphics**: Three.js, React Three Fiber, React Three Drei
- **Animations**: Framer Motion 12
- **Language**: JavaScript/React
- **Package Manager**: Bun

## Getting Started

This project uses Bun as the package manager. Install Bun, then:

```bash
bun install   # install all dependencies
bun dev       # start the development server
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.
