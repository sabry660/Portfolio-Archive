# Mohamed Sabry - Front End Developer Portfolio

An interactive 3D portfolio website showcasing modern web development capabilities through an immersive digital experience. This project demonstrates expertise in front-end development, 3D web graphics, and interactive user interfaces.

## Portfolio Overview

This portfolio features an interactive 3D environment built with Three.js and Ammo.js physics engine, allowing visitors to explore projects through an engaging spatial interface. The site combines modern web technologies with creative design to present professional work in a memorable format.

## Featured Projects

The portfolio showcases 12 professional web development projects:

- **Word of mouth** - Modern digital platform built with Angular
- **Fluency Sprint** - Language-learning platform using React, NestJS, and Stripe
- **Palestinian Stories** - Digital storytelling platform with Angular, Python, Django, and AWS
- **Catch Recruitment** - Professional recruitment platform using React, Next.js, Docker, and Spring Boot
- **CHUWI** - High-scale e-commerce experience for global technology brand
- **Dashboard** - Hotel management dashboard with Angular, Spring Boot, and AI integration
- **Guest Portal** - Premium hotel guest portal with Angular, Node.js, Nest.js, and Tailwind CSS
- **Villa Misk Hotels** - Hospitality website using React, TypeScript, and Tailwind CSS
- **Cafe Website** - Modern café website with responsive design
- **Clothes Shop** - E-commerce fashion platform with shopping functionality
- **The Daily Drip** - Polished café brand experience with Angular and TypeScript
- **Voya Travel** - Travel platform with immersive visuals and GSAP animations

## Technical Features

- Physics engine (Ammo.js) combined with 3D rendered objects (Three.js) for real-time movement, collision detection, and interaction
- Desktop and mobile responsiveness with both keyboard and touch screen controls
- Raycasting with event listeners for user touch and click interaction
- FPS tracker to monitor frame rate and rendering performance
- Asset compression with webpack plugin for optimized site load times
- SEO optimization with proper meta tags and structured data

## Usage

To run the project locally, clone the repository, install dependencies, and run using webpack's dev server:

```bash
npm install
npm run dev
```

Navigate to localhost:8080 in your browser to view the portfolio.
